# Champions Retreat Golf Club: concept preview

A website concept for Champions Retreat Golf Club in Evans, Georgia, designed by Caleb Garrard. This is a preview, not the club's live site. Photographs, film, logo and course information belong to Champions Retreat.

The land model uses elevation from the AWS Terrain Tiles (USGS 3DEP and other public sources) and course, water, woods and buildings from OpenStreetMap (© OpenStreetMap contributors, ODbL).
